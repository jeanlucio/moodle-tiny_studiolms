# 📖 Usage

**Building content with blocks:**

1. Open any TinyMCE editor (a page, a section summary, an activity description…).
2. Click the **StudioLMS** button in the toolbar, or go to **Tools → StudioLMS**.
3. In the **Components** tab, click a block to add it to the canvas. Select a block on the canvas to
   edit its properties in the side panel; use the arrows to reorder and the × to remove it.
4. Click **Insert** to place everything in the editor, then save the page as usual.

**Blocks inside a grid:** click a column of a Grid Cards block to make it the place for the next blocks, then
pick blocks from the library; each one is added to that column and selected. Click a block in a column to edit
it like any other block: its own settings replace the grid's in the toolbar, its text is typed right on the canvas,
and the arrows and the × on the block move it up or down in its column and remove it. **Grid settings** (at the
start of the toolbar) or a click on the grid itself brings back the settings of the grid.

To change a block later, click it inside the editor and open StudioLMS again — it reopens with that
block's settings.

**Reusing layouts:**

* **Save as template** stores the current canvas in **My Templates**; each template can be starred
  to appear in **Favourites**.
* **Export** and **Import** (in **My Templates**) move templates between sites as `.json` files. Tick the
  templates to export: the button then reads **Export selected (n)**. With nothing ticked it reads
  **Export all** and takes all your templates; for a site manager that also includes the site templates, and
  the line under the button says so.
* **Ready-made Layouts** holds the layouts that ship with the plugin; load one and change it as you like.
* **Site Templates** holds the institution's shared layouts. Teachers apply them; site managers
  can also save and delete them.

**Using AI (when available):**

* **AI Block** — describe one block in plain language ("a red warning card about the exam"), review
  the preview, then insert it, configure it further or save it as a template.
* **AI Layout** — give a name, the pedagogical context, optional block types and a colour palette;
  the AI assembles a multi-block layout for review.
* **AI Chat** — paste a syllabus, lesson plan or activity list. The assistant proposes a complete
  page (or asks whether a resource list should be Grid Cards or Resources) and shows an action card;
  nothing is applied until you confirm it.
* Several blocks (infographics, callout, card, accordion, resources) also have their own
  **Generate with AI** button in the properties panel.

AI output is always shown as a preview first; the teacher decides what goes into the course.
